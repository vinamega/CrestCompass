# CrestCompass

Geo-aware core module enables real-time location-based analytics and data processing via concurrent, event-driven architecture.

CrestCompass is built to be simple and practical, focusing on doing one thing well.

**Why CrestCompass?**

- Geo-aware core module enables real-time
- location-based analytics and data processing
- via concurrent, event-driven architecture

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/CrestCompass.git`
2. `cd CrestCompass`
3. Install in editable mode: `pip install -e .`

## Configuration

CrestCompass is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
